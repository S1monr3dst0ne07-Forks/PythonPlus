# Python+ README.md

# How to use:

## For MacOS / Linux
- Move Python+ to your Documents folder
- Open Terminal
- Type cd ~/Documents/[your version of PythonPlus. If you pulled from Github, the folder is simply called "PythonPlus", but if you installed a release, it is "PythonPlus" followed by its version.]
- Type python3 -m pyplus to run the file examples/hello.pyplus!

## For Windows:
- NOTICE: Windows is not fully supported by Python+. In future releases, we will have instructions for Windows users.

## Syntax for v0.4

To declare variables:
[varname] := [value]

To print a value:
print [variable, string, or maths]

Available maths operators:
+, -, /, *, (, )

Other syntax:
Commas
